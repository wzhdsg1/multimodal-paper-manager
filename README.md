# 本地多模态AI文献管理助手

## 项目简介
本项目是一款**本地运行的多模态AI文献管理工具**，支持学术论文的自动分类、语义搜索，以及图片的以文搜图功能。所有数据（论文、图片、向量索引）均存储在本地，无需联网即可使用，保障数据隐私与使用便捷性。
项目基于「文本/图像嵌入 + 向量数据库」的核心思路实现，兼顾命令行批量调用与可视化界面操作，满足不同使用场景需求。

## 核心功能列表
- **论文管理**：
  1. 单篇论文添加：自动提取论文信息、分类到对应主题文件夹、生成文本嵌入并索引
  2. 批量整理论文：对指定文件夹内的所有PDF论文进行一键分类、移动与索引
- **论文搜索**：
  1. 搜索论文文件：根据语义查询返回相关的论文文件列表
  2. 搜索论文片段：根据查询返回论文内的精准文本片段及页码
- **图片管理**：
  1. 添加图片索引：上传图片并生成多模态嵌入
  2. 以文搜图：根据文本描述返回最相似的本地图片
- **本地存储**：所有数据（论文、图片、向量数据库）均保存在项目 `data/` 目录下

## 新增：核心功能实现细节
### 1. 论文自动分类模块（core/classifier.py）
#### 实现思路
- 模型选型：采用 `BART-Large-MNLI` 零样本分类模型（无需标注数据，适配学术论文主题分类场景）；
- 核心流程：
  1. 提取PDF论文的标题/摘要（优先标题，无标题则提取前500字）；
  2. 预设论文主题列表（如NLP、ML、CV、Data Mining等）；
  3. 模型计算文本与各主题的相似度，选择相似度最高的主题作为分类结果；
  4. 调用 `utils/file_operate.py` 将论文移动到对应主题文件夹。
#### 技术难点与解决方案
- 问题：部分论文无标题/摘要，分类准确率低；
- 解决方案：提取论文前500字作为补充文本，同时增加「Other」兜底分类文件夹，避免分类失败。

### 2. 文本/图像嵌入模块（core/embedding.py）
#### 文本嵌入（论文搜索）
- 模型：`sentence-transformers/all-MiniLM-L6-v2`（轻量、速度快，适合本地运行）；
- 流程：将论文文本/搜索查询编码为384维向量，保证向量空间语义对齐；
- 优化：对长文本（>512token）进行分段编码，取均值作为论文整体向量。

#### 图像嵌入（以文搜图）
- 模型：OpenAI CLIP（ViT-B-32）（多模态模型，支持文本-图像跨模态匹配）；
- 流程：
  1. 图片预处理（Resize到224×224、归一化）；
  2. CLIP模型分别编码图片/文本描述为512维向量；
  3. 计算向量余弦相似度，匹配最相似的图片。

### 3. 向量数据库模块（core/vector_db.py）
- 选型：ChromaDB（轻量级、无需额外部署、支持本地持久化）；
- 核心操作：
  1. 初始化：按「论文/图片」分不同Collection（集合），避免向量混淆；
  2. 插入：将嵌入向量+元数据（文件路径、页码、文件名）插入数据库；
  3. 搜索：将查询向量与数据库中向量计算余弦相似度，返回Top-K结果；
- 优化：设置向量数据库持久化路径到 `data/chroma_db/`，保证重启后数据不丢失。

### 4. PDF处理模块（core/pdf_processor.py）
- 工具：PyPDF2（轻量、易部署，满足文本提取需求）；
- 核心功能：
  1. 提取PDF所有页面文本，保留页码关联；
  2. 过滤无效字符（如乱码、空白符），清洗文本数据；
  3. 长文本分段（按段落/固定长度），适配嵌入模型输入限制。

### 5. 异常处理与用户体验优化
- 低置信度提示：搜索结果相似度低于阈值（0.5）时，返回友好提示；
- 批量处理容错：批量整理论文时，单个PDF处理失败不中断整体流程，记录错误日志；
- 路径兼容：适配Windows/mac/Linux不同路径格式（如 `\` vs `/`），避免路径错误。

## 使用说明
项目支持**命令行调用**（符合作业评测接口规范）与**Streamlit图形界面**两种使用方式。

### 方式1：命令行调用（main.py统一入口）
项目根目录下的 `main.py` 为统一入口，支持以下核心功能调用：

#### （1）添加并分类单篇论文
```bash
python main.py add_paper <PDF文件路径>
# 示例：
python main.py add_paper "D:\课程\多模态\论文\example_paper.pdf"
```

#### （2）批量整理论文文件夹
```bash
python main.py organize_papers <论文文件夹路径>
# 示例：
python main.py organize_papers "D:\课程\多模态\待整理论文"
```

#### （3）搜索相关论文文件（整篇）
```bash
python main.py search_paper_file <查询关键词> --top_k <返回数量>
# 示例：
python main.py search_paper_file "NLP在管理领域的应用" --top_k 5
```

#### （4）搜索论文精准片段
```bash
python main.py search_paper <查询关键词> --top_k <返回数量>
# 示例：
python main.py search_paper "Transformer模型的语义编码" --top_k 3
```

#### （5）添加并索引单张图片
```bash
python main.py add_image <图片文件路径>
# 示例：
python main.py add_image "D:\课程\多模态\图片\sunset.jpg"
```

#### （6）以文搜图
```bash
python main.py search_image <图片描述关键词> --top_k <返回数量>
# 示例：
python main.py search_image "海边日落的风景图" --top_k 2
```

### 方式2：Streamlit图形界面（可视化操作）
项目根目录下的 `app.py` 提供更友好的图形界面，执行以下命令启动：
```bash
streamlit run app.py
```
启动后会自动在浏览器打开界面，左侧侧边栏选择功能（添加论文、搜索、图片管理），按界面提示操作即可。

## 技术选型说明
| 模块          | 技术/工具                          | 用途                                  | 选型理由                                                                 |
|---------------|------------------------------------|---------------------------------------|--------------------------------------------------------------------------|
| 文本嵌入模型  | Sentence-Transformers（all-MiniLM-L6-v2） | 论文文本、搜索查询的向量编码          | 轻量级、速度快、语义表征能力强，适合本地低算力环境                        |

| 向量数据库    | ChromaDB                           | 存储文本/图片的向量索引，支持语义搜索 | 轻量级、无需额外部署、支持本地持久化，API简洁易集成                      |
| PDF处理       | PyPDF2                             | 提取论文文本与页码信息                | 轻量无依赖，满足基础文本提取需求，适配本地运行场景                        |
| 图像处理      | Pillow                             | 图片加载与格式转换                    | Python生态主流图像处理库，易集成、兼容性强                              |
| 可视化界面    | Streamlit                          | 提供图形化操作入口                    | 开发效率高，无需前端知识，一键生成交互界面，适配快速开发与作业演示        |

## 项目亮点与可扩展方向
### 1. 项目亮点
- 本地化部署：所有数据/模型均本地运行，无数据隐私泄露风险，无需联网；
- 多模态融合：兼顾文本（论文）与图像的嵌入、搜索，适配多类型学术数据管理；
- 双入口设计：支持命令行批量调用（满足评测规范）+ 可视化界面（提升易用性）；
- 鲁棒性优化：完善的异常处理、路径兼容、低置信度提示，避免程序崩溃。

### 2. 可扩展方向
- 支持更多文件格式：如Word、Markdown等文本文件的嵌入与搜索；
- 模型轻量化：替换为更小的嵌入模型（如DistilBERT），提升低配置设备运行速度；
- 多语言支持：增加多语言嵌入模型，适配英文/中文论文混合分类与搜索；
- 可视化分析：增加论文/图片的相似度可视化图谱，直观展示数据关联。

## 注意事项
- 所有数据默认存储在项目根目录的 `data/` 文件夹下（论文：`data/papers/`；图片：`data/images/`；向量索引：`data/chroma_db/`）；
- 首次运行功能时，模型会自动下载（需确保网络可访问Hugging Face，或提前手动下载模型到本地缓存）；
- 若遇到模型下载缓慢，可手动下载模型文件到 `~/.cache/huggingface/` 目录（Windows：`C:\Users\用户名\.cache\huggingface\`）。
